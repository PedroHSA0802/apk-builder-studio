APK Builder Studio

The fully GUI-driven platform for turning Kivy and KivyMD apps into APKs and AABs — from setup to AI-assisted error analysis.

The full documentation with a step-by-step tutorial lives right on Screen 1 in the app — everything is explained there.

  • Zero terminal — complete WSL & Ubuntu setup with one click.
  • Seamless transfer — Windows projects automatically mirrored into the Linux environment.
  • Smart builds — CameraX & ML features via checkbox, spec templates included.
  • SamAI assistant — build crashes and device errors analyzed and fixed for you.
Screen 1

The fully automated setup

The complete Linux and Buildozer setup — with no console commands at all.

Activate WSL & Ubuntu
One click on "Activate WSL", a restart, and Ubuntu is downloaded and set up automatically.
Set up Buildozer & SDK
Pick the right config from the dropdown. Need a Play Store-ready AAB? "md2.16 kb" creates a dedicated Python 3.14 venv with 16 KB alignment. The Android SDK/NDK are also installed via a button, exactly to server spec.
Broom & Bomb — repair
Broom clears global caches when a build gets stuck. The Bomb button resets the entire WSL install for a clean restart when needed.
Screen 2

The project manager

Manage projects without manually copying files back and forth between Windows and Linux.

Import a new project
Pick a folder in Windows Explorer — it's copied to Linux automatically and set as the active project.
Choose a WSL project
Select and activate an existing Linux project directly.
WSL explorer
Opens the Linux folder of the active project, or the main folder to manage older projects.
Screen 3

Build, specs & native modules

Add native Android features and manage your configurations in one place.

Create a spec & inject modules
Start from the general spec in the docs, then check off native features like CameraX, Text Recognition, Face Detection, Barcode Scanner, Text-to-Speech & Speech-to-Text — Java helpers and spec entries are added automatically.
Tutorial & SamAI safety net
The Screen 1 docs include a complete camera-app tutorial (take a photo, extract text, read it aloud). Since every project has its own dependencies, the general spec can still throw errors at first — SamAI fixes it in the next step.
Smart templates
Save finished spec files under your own name and reuse them for new projects from the dropdown.
Targeted clean & build
"Clean P4A + Buildozer" clears only the active project's caches, then "Build APK/AAB" starts compiling.
Screen 4

Deployment & debugging

Install apps straight to your phone, capture errors, and start the analysis.

Wi-Fi & USB install
Install finished APKs, or unpack and install AABs Play Store-style for the connected device — at the press of a button.
Live logcat
"Debug" records the logcat and streams the error live in the terminal the moment the app crashes.
Start the AI analysis
"IDE / SamAI analyses" opens the integrated IDE in your browser with your personal assistant SamAI for troubleshooting.
The integrated IDE

SamAI

The two-click fix for build and device errors — with the active project's file tree built in.

Problems with the build?
"Problems with the build (APK/AAB)" analyzes the log from Screen 3 and delivers the exactly corrected buildozer.spec — even while your module spec still needs adjustments.
App crashing on the device?
"App won't start [...]" evaluates the logcat. Enable the affected .py or .kv files in the file tree, and SamAI spots the logic error and delivers the fix.
One-click "Apply"
No manual copy-pasting needed — one click writes the corrected code straight into your project files. Then head back to Screen 3 and restart the build.
